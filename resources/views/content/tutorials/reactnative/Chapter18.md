# 🔔 Understanding Notifications

Notifications are messages displayed outside the application UI.

They help users stay informed even when the app is closed.

---

# 🔹 Notification Types

There are two major notification types:

| Type               | Source           |
| ------------------ | ---------------- |
| Local Notification | Generated by app |
| Push Notification  | Sent from server |

---

# 🔹 Local Notifications

Local notifications are created directly inside the application.

No backend server is required.

---

## Examples

- Daily expense reminder
- Budget exceeded alert
- Monthly spending summary

---

## Benefits

✅ Works offline
✅ Easy to implement
✅ No backend required

---

# 🔹 Push Notifications

Push notifications are sent from remote servers.

---

## Examples

- Promotional offers
- Account alerts
- Multi-device updates

---

## Requires

- Backend server
- Push notification service
- Device registration token

---

# 🔹 Notification Flow

```text id="y4prf0"
Application Schedules Notification
                ↓
Operating System Stores Notification
                ↓
Notification Trigger Executes
                ↓
User Receives Alert
```

# 🔹 Why Permissions are Required

Operating systems require permission before sending notifications.

This protects users from spam and unwanted alerts.

---

# 🔹 Request Notification Permission

📁 `src/services/notificationService.ts`

```tsx id="rm0u7f"
import * as Notifications from "expo-notifications";

export const requestNotificationPermission = async () => {
    const { status } = await Notifications.requestPermissionsAsync();

    if (status !== "granted") {
        alert("Notification permission denied");

        return false;
    }

    return true;
};
```

---

# 🔹 Permission States

| Status       | Meaning                  |
| ------------ | ------------------------ |
| granted      | Notifications allowed    |
| denied       | User rejected permission |
| undetermined | Not requested yet        |

---

# 🔹 Best Practices for Permissions

✅ Ask permission contextually

✅ Explain why notification is useful

✅ Handle denied state properly

✅ Avoid repeated prompts

# 🧪 ExpenseApp Example

📁 `src/app/settings.tsx`

```tsx id="1r9y0v"
import React from "react";

import { View, Text, Pressable } from "react-native";

import * as Notifications from "expo-notifications";

import { style } from "../styles/styles";

export default function SettingsScreen() {
    const scheduleReminder = async () => {
        const { status } = await Notifications.requestPermissionsAsync();

        if (status !== "granted") {
            alert("Permission required");

            return;
        }

        await Notifications.scheduleNotificationAsync({
            content: {
                title: "Expense Reminder",

                body: "Add today's expenses!",
            },

            trigger: {
                hour: 20,
                minute: 0,
                repeats: true,
            },
        });

        alert("Daily reminder scheduled");
    };

    return (
        <View style={styles.container}>
            <Text style={styles.title}>Notification Settings</Text>

            <Pressable style={styles.button} onPress={scheduleReminder}>
                <Text style={styles.buttonText}>Enable Daily Reminder</Text>
            </Pressable>
        </View>
    );
}
```
