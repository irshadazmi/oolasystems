# Chapter 7: React Native Tutorial – StickerSmash with Expo

---

In this chapter, you will build a fun React Native application called **StickerSmash** using **Expo**.

StickerSmash is a cross-platform application that runs on:

- Android
- iOS
- Web

using a single codebase.

This tutorial helps you understand how real-world Expo applications are built using:

- Expo Router
- Bottom tabs navigation
- Flexbox layouts
- Image Picker
- Modal
- FlatList
- Gestures
- Screenshot capture
- Platform-specific handling

---

# 🎯 What You Will Learn

By the end of this tutorial, you will:

- Create an Expo app using TypeScript
- Use Expo Router navigation
- Build layouts using Flexbox
- Select images from device gallery
- Create sticker selection modal
- Use FlatList for rendering stickers
- Add touch interactions
- Capture screenshots
- Save images to device storage
- Configure app icon and splash screen
