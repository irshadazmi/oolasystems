# Tutorial: Programming Fundamentals with C# and .NET

Welcome to this hands-on tutorial where we will build a strong foundation in **Programming Fundamentals using C# and .NET**.

In this journey, you will learn how to write clean, efficient, and scalable code that forms the backbone of enterprise applications.

We will use modern tools and best practices including **Visual Studio / VS Code, .NET SDK, and GitHub integration**.

Let’s get started.

---

## About this tutorial

The primary goal of this tutorial is to help you **learn by coding real-world examples** rather than just understanding concepts theoretically.

Using the GitHub repository:  
👉 `https://github.com/irshadazmi/DotNetFundamentals` [(github.com in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fgithub.com%2Firshadazmi%2FDotNetFundamentals")

we will progressively build and enhance small **console-based applications**, covering both **core programming concepts** and integration with modern .NET features.

---

## What you will learn

This tutorial is carefully designed to take you from **basic programming constructs** to **advanced fundamentals**. You will learn:

### 🚀 Project Setup & Fundamentals

- Install and configure **.NET SDK**
- Create your first **C# console application**
- Understand project structure and compilation

### 📐 Core Programming Concepts

- Variables, data types, and operators
- Control flow (if, switch, loops)
- Methods, parameters, and return types

### 🧩 Object-Oriented Programming

- Classes and objects
- Constructors and properties
- Inheritance, polymorphism, and interfaces

### 📏 SOLID Principles

- Learn the 5 SOLID principles
- Apply them in small coding exercises
- Understand why they matter in enterprise systems

### 📊 Data Structures Basics

- Arrays, Lists, Dictionaries
- Stacks and Queues
- Practical coding exercises

### 🔎 LINQ Deep Dive

- LINQ syntax and query operators
- Filtering, projection, grouping
- LINQ to Objects vs LINQ to SQL

### ⚡ Async & Multithreading

- Task-based async programming
- async/await keywords
- Parallel programming patterns
